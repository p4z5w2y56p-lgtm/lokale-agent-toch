# Trading playbook (v1)

This file is the agent's "training": rules and lessons that get refined after
reviewing scorecards and the trade journal. Edit it, re-run the replay, compare.

## Rules
1. Capital preservation beats profit. When unsure, do nothing.
2. Never chase a token that already moved sharply; wait for a pullback.
3. Small positions. One idea should never be able to hurt the whole portfolio.
4. Every trade needs a one-sentence reason that mentions a specific number from the data.
5. Selling a losing position early is allowed and often right.
6. Doing nothing is a valid answer. Return an empty trades list.
